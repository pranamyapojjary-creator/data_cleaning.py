# Data Cleaning and Reporting Automation

## 1. Project Overview
This project demonstrates data cleaning and reporting automation using Python.

## 2. Tools Used
- Python
- Pandas
- CSV files
- GitHub

## 3. Data Cleaning Operations
- Identified missing values.
- Removed duplicate records.
- Filled missing numerical values using the column mean.
- Filled missing text values with "Unknown".
- Exported the cleaned dataset to a CSV file.

## 4. Results
- Original records: 11
- Records after removing duplicates: 10
- Duplicate records removed: 1
- Missing values handled: 2

## 5. Output
The cleaned dataset is saved as cleaned_data.csv.

## 6. Conclusion
This project demonstrates basic data preprocessing and provides a
foundation for automated reporting.
